# CORE-CRUSH 設計書（現行仕様の入口）

CORE-CRUSHは、1v1・1v2・2v2に対応するFPS/TPSドッジボール。8秒で爆発するコアを、跳ね返しのラリーとフェイントで相手へ押し付け合う。

- 現行仕様は本フォルダの章別ファイル。ベースは企画設計書v2.0（2026-10-06）。
- `archive/v2.0/` は章分け前の原文、`archive/GDD_v1.0.md` は**旧版**（2026-10-03頃、D:/T3test/GDD.md の写し）。どちらも履歴資料であり、実装の根拠にしない。
- 旧版とv2.0が食い違う場合はv2.0を優先する。v2.0からの変更は下の「変更履歴」と `docs/decisions/` に記録する。

## 設計の優先順位

品質の優先順位：入力と判定の納得感 → 球の読みやすさ → 打撃の爽快感 → キャラクター性 → 背景の豪華さ。配信先の都合で、この順序を逆転させない。

本書の手法・ツール・初期数値より、品質・再現性・保守性に優れた方法が見つかった場合は採用してよい。目的と受け入れ条件を保ち、比較結果と変更理由を `docs/decisions/` に残す。8秒制や操作の意味など、要件そのものを変える場合は企画変更として明示する。

## 旧版GDD v1.0との主な相違（v2.0を採用）

| 論点 | 旧版v1.0 | 現行 |
|---|---|---|
| 対戦形式 | 1v1のみ | 1v1・1v2・2v2 |
| フェイントのキー | Q | F。Qはロック対象の巡回、球召喚はC |
| キャッチと跳ね返しの受付 | 別々の幅（キャッチが最短） | 同じ受付W。防御値で両方が変化 |
| キャッチ報酬 | +1.0固定 | so-so 0.25／good 0.5／just 1.0 |
| 返球の球種 | ストレート相当に固定 | WASDで選べる |
| 上カーブの回避方向 | 左右のみ | **左右のみ**（v2.0初期案の全方向から企画変更で戻した。変更履歴参照） |
| 通信の判定 | 受け手権威 | ホスト1人を最終判定者とするスター接続（初期案） |
| 画像生成 | Gemini系プラグイン | GPT Image（T3 Code） |
