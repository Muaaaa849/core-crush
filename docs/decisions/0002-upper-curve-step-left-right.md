# 0002 上カーブは左右ステップでのみ追尾解除する（企画変更）

- 日付：2026-10-07
- 状態：採用（要件）

## 決定

上カーブの有効ステップ方向を「左右のみ」とする。前後ステップでは追尾を継続する。

| 球種 | 追尾を解除できるステップ方向 |
|---|---|
| ストレート | 全方向 |
| 左右カーブ | 前後のみ |
| 上カーブ | 左右のみ |

方向は、球を受ける本人のコート前後軸を基準にする（rules.md）。

## 経緯

- 旧版GDD v1.0は「左右のみ」。v2.0は原案未指定として「全方向」を初期案にしていた。
- ユーザー指定で「左右のみ」を採用。左右カーブと逆の関係にして、球種と回避方向の読み合いを作る。

## 影響

- rules.md「キャッチ・跳ね返し・ステップ」「投げる・曲げる・惑わせる」、受け入れID R04。
- 上カーブに対して「前後へ逃げる」ことが誤りになるため、練習モードで失敗理由を示す（feel.md「練習」）。
