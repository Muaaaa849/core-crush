# 0004 M1のルール部分（sim）の構造

- 日付：2026-10-07
- 状態：採用。下の論点は2026-10-07にユーザーが推奨案で確定し、rules.md「M1細則」へ反映した（試合球は拡大）
- 出典：GPT-6 Astraへの設計相談（読み取りのみ）を親が整理

## 決定

### 時間

- simは固定60Hzで更新する。「F」は描画枚数ではなく `1F = 1/60秒` の時間単位。
- 時刻は整数の `1/60,000秒` 単位（1F＝1,000、8秒＝480,000、80ms＝4,800）。`elapsed += dt` の累積はしない。
- 入力・接触・中央通過はtick境界へ丸めず、tick内で最も早い事象から時刻順に解決する。
- 危険時計は残り時間を減らさず、`{ side, expiresAt }` を持つ。中央通過時だけ `expiresAt = 通過時刻 + 8秒` に更新する。
- 同時刻の順序：爆発 → 入力と行動境界 → 中央通過・防御接触・直撃 → ダメージとKOをまとめて勝敗判定を1回。期限ちょうどの通過は爆発を優先する（rules.md）。
- 受付は半開区間 `[開始, 終了)`。
- 中央通過は球の**中心**が平面z=0に達した時刻（tick内の線分補間）。

### 構造（必要になった時点で追加する）

| ファイル | 責務 |
|---|---|
| `src/sim/config.ts` | 数値の唯一の定義（時間、球速、報酬、能力係数、コート寸法、判定形状、ジェスチャー閾値） |
| `src/sim/types.ts` | 状態・入力・イベントの型 |
| `src/sim/sim.ts` | 初期化、1tick更新、時刻順解決、資源・所有権・ラウンド |
| `src/sim/ball.ts` | 飛翔、中央通過、掃引接触、球速・威力 |
| `src/sim/actions.ts` | 投擲、防御、ステップ、フェイント、召喚、ジェスチャー評価 |
| `src/presentation/camera-policy.ts` | カメラ種別の決定（three.js非依存） |

- `step(state, commands, config) → { state, events }`。simは時刻取得・乱数・描画・DOMを参照しない。状態は複製できる通常のデータ。
- 入力は時刻と順番付きのイベント（移動、減衰前のマウス視角量、ボタン押下・解放）。botも同じ入力を使い、成功結果を直接注入しない。
- コストは0.25単位の整数（上限5＝20）。
- ブラウザ間のビット単位一致はM1の契約にしない（M2はホストが最終結果を配信して訂正する）。

### 追尾とステップ

- 追尾は「一定速度で誘導点へ向かう」方式。誘導点＝受け手の防御点＋球種別の曲がりオフセット（時間とともに0になり、最後は受け手へ直進）。旋回速度の上限は設けず、移動する受け手との掃引接触で判定する。これにより通常歩行では外れない（R03）。
- 追尾中は装飾・床との衝突で攻撃判定を失わない。追尾解除後と狙い投げは、床・外周への最初の衝突で失う。
- ステップ方向は開始時に、受け手の陣の固定基底（前＝中央方向）へ移動ベクトルを射影して分類する。カメラの向きでは変わらない。
- 有効方向：ストレート＝全方向、左右カーブ＝前後のみ、上カーブ＝左右のみ（0002）。解除時は現在の速度で直進を続ける。無敵なし。

### 防御ジェスチャー

- クリック時刻p、接触時刻cに対し、`[p−80ms, min(p+50ms, c)]` のマウス入力で方向を決める。接触後の入力は使わない。
- 縦成分は物理的な「手前へ引く」を正とし、Y反転を適用しない。カメラ感度の25%減衰は視点にだけ掛け、判定量には掛けない。
- 返球の球種は接触時点の移動キーで決める。

## 論点と推奨（確定内容は rules.md「M1細則」）

| 論点 | 推奨 |
|---|---|
| 投球後のカメラ | 投球後8FはFPSを維持し、硬直終了から100msでTPSへ |
| キャッチ全体24F・空振り54Fの起点 | クリック起点。跳ね返し成功後の6Fだけ接触起点 |
| 斜め・無入力・壁で動けないステップ | 斜めは主成分、同値は前後。無入力は不成立。動けなければ消費も解除もなし |
| 追尾解除の時点 | ステップ成立の開始時に、自分を追っている球だけ解除 |
| パリィ方向の基準 | 球種名ではなく、受け手の視点から見た実際の入射方向 |
| 防御範囲160度の評価時点 | 接触時の論理視点（揺れ・肩位置は使わない） |
| 240ms下限 | 発射時の距離による速度制限。相手が自分から近づいて早く当たるのは許容 |
| 倍率の合成 | 基本値×能力倍率×危険倍率×(1＋ラリー加算)、その後に総上限 |
| 爆発後の新球 | 1秒後に出現、その1秒後に操作と時計を開始（計2秒） |
| M1の球召喚 | 共通の球召喚だけ入れる |
| 同時押し | 1時刻1行動。優先順位を資料で固定 |
| 試合球の見せ方 | 直径0.22mはTPSで小さすぎる（M0で確認）。判定半径と表示の扱いを決める |
