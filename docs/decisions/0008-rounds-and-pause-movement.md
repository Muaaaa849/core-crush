# 0008 ラウンドと勝敗、爆発後の停止中の移動

- 日付：2026-10-07
- 状態：採用。停止中の移動はユーザー指定（要件）、ラウンドの区切りの時間は初期案
- 背景：勝敗の処理がなく、HPが0になると以後ずっと動けなかった（ユーザー報告「突然動けなくなる」）。また、相手の爆発でこちらも2秒止まるのが不快（ユーザー指定）

## ラウンドと勝敗（rules.md「一試合の流れと勝敗」をsimへ入れる）

- 相手チーム全員のHPが0になったらラウンド勝利。2ラウンド先取で試合終了。
- ラウンド時間180秒。時間切れは各チームの残存HP合計÷開始時最大HP合計で比べ、同率は引き分け。
- 同時刻の直撃・爆発で両者が0になったら引き分け。引き分けはどちらにも得点を与えず、同じ番号のラウンドをやり直す。
- 勝敗の確定は、同時刻の直撃・爆発をまとめた後に1回だけ（R10、M1細則「同時刻の処理順」）。
- 確定した時刻から3秒は結果表示で、全員停止し、球・時計も止める【初期案】。
- その後、全員を初期位置・HP全快・コスト1・ステップ2へ戻し、球を「前ラウンドの最初の球と逆の陣」の供給位置に出す。1秒後に操作と危険時計を開始する（既存の開始と同じ）。ラウンド時間もここから数える。
- 試合終了後のsimは止まったまま。画面側が5秒後に新しい試合を始める（練習用）【初期案】。

状態に `match: { round, wins: { p1, p2 }, phase: 'play' | 'result' | 'over', roundEndsAt, nextRoundAt?, firstBall }` のような通常のデータを持つ（途中保存・再実行に含まれる）。事象は `round-end`（勝者または引き分け、理由：KO／時間切れ）、`round-start`、`match-end`。

## 爆発後の停止中の移動（要件）

- 爆発から新球の時計開始まで（計2秒）も、歩行とステップはできる。ステップ回数の回復は従来どおり相手陣の時計が動いている間だけ。
- 投擲・キャッチ・跳ね返し・フリ・球召喚は、従来どおり時計の開始後。
- ラウンド開始前の1秒と、ラウンド結果の3秒は動けない（開始手順「1秒後に操作と危険時計を同時開始」）。

## 受け入れ条件

| ID | 期待する振る舞い |
|---|---|
| M8-1 | P2のHPが0になった時刻にround-end（勝者P1、KO）が1回だけ出て、P1の勝ち数が1増える |
| M8-2 | 同時刻に両者が0になる（爆発・直撃の組合せ）と引き分け。得点なし、同じラウンド番号でやり直す |
| M8-3 | 180秒で時間切れ。残りHP割合の高い側が勝ち、同率は引き分け |
| M8-4 | 結果の3秒は移動・行動・球・時計が止まる。その後、位置・HP・コスト・ステップが初期値、球は前ラウンドの最初の球と逆の陣に出て、1秒後に時計開始 |
| M8-5 | 2勝でmatch-end。以後のsimは何も起きない |
| M8-6 | 爆発後の2秒の停止中も歩行・ステップで位置が変わる。投擲・防御・フリ・召喚は成立しない |
| M8-7 | HPが0になって永久に動けない状態が起きない（ランダム操作の長時間試合で、試合終了まで毎ラウンド初期化される） |
| M8-8 | ラウンドをまたいでも、途中保存からの再実行が一致する |
