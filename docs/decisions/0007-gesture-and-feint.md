# 0007 防御のマウス方向（ジェスチャー）とフリ（M1スライス5）

- 日付：2026-10-07
- 状態：採用（【初期案】は試遊で変更しうる）
- 出典：GPT-6 Astraへの設計相談（読み取りのみ）を親が整理

## ジェスチャー

### 入力と判定の場所

操作側（controls）は、マウスの移動量を**感度適用後・防御中の減衰前・Y反転前の視角（度）**に直してsimへ送る。方向の分類と成否はsimが決める（0004「入力は減衰前のマウス視角量」）。M2でも同じ値をホストへ送り、クライアントの分類結果は使わない。

```ts
{ kind: 'mouse'; rightDegrees: number; pullDegrees: number } // 右へ動かす＝right正、手前へ引く＝pull正
```

M1では描画1フレーム分の移動をまとめて1コマンドにし、時刻は既存の実行器と同じ（そのフレームでsimへ渡す時刻）とする。フレーム単位の時刻の粗さ（60fpsで約17ms）は試遊で問題になれば、DOMイベント時刻からの換算へ変える。

### 方向の分類

- 跳ね返しを押した時刻p、接触時刻cに対し、閉区間 `[p − 80ms, min(p + 50ms, c)]` のサンプルを合計する（X＝右、Y＝手前）。
- `max(|X|, |Y|) < 2度` ならニュートラル。2度ちょうどは方向入力。
- 水平が優勢ならXの符号で左／右。縦が優勢ならY正＝上（手前へ引く）、Y負＝無効。
- 主成分が同値なら、区間内の新しいサンプルから順に、最初に主成分が決まるものを採用。それも同値なら水平【初期案】。
- 往復は相殺する。接触後・締切後のサンプルで結果を変えない。
- 進行中の跳ね返しに必要なサンプルは受付終了まで保持し、それ以外は80ms分だけ持つ（状態の一部として途中保存に含まれる）。

### 必要な方向（実際の入射方向）

接触した線分の球速度の逆向き（受け手から見て球が来る向き）を、受け手の論理視点（yaw）で評価する。球種名・曲がりオフセットは使わない。

- 水平角 h（右が正）、仰角 v（上から来るほど正）。正面範囲 |h| ≤ 80°（160度）は従来どおり、外ならキャッチ・跳ね返しとも失敗。
- `max(|h|, max(v, 0)) < 10°` ならニュートラル【初期案】。それ以外は `v > |h|` なら上、そうでなければhの符号で右／左（同値は水平）。
- 右から来る球＝右へ振る、左から来る球＝左へ振る、上から来る球＝手前へ引く（rules.md「跳ね返しの方向入力」）。

### 適用範囲と失敗

- **方向が必要なのは跳ね返しだけ**。キャッチは受付時間と正面160度だけで判定する【初期案】（feel.md 操作表「左クリック＋マウス方向＝跳ね返し」「右クリック＝キャッチ」）。
- 跳ね返しの方向が合わずに球が体へ接触した場合は被弾（HP減少・攻撃消失・ラリーリセット・報酬なし）。防御は終わり、押した時刻を起点とする跳ね返し空振りの硬直へ移る【初期案】（被弾で硬直が消えないように）。事象 `hit` に `required` と `actual` を付けて表示に使う。別の `whiff` は出さない。

### 感度の減衰（表示側）

成立したキャッチ・跳ね返しの開始から、その受付の終了時刻まで、視点の回転だけを25%にする。判定用のマウス量は減衰前。simは防御の成立時に事象 `defense-start`（`endsAt`＝受付終了）を出し、操作側はそれを見て減衰する。被弾・爆発で減衰を解除する。

## フリ（F、R06）

- 状態 `{ kind: 'feint'; startedAt; endsAt }`。条件は「生存・操作可能・球を保持・行動なし・コスト0.25以上」。開始時にコスト0.25（内部単位1）を消費し、返還しない。
- 長さは本投げの投げ始めと同じ8F、歩行30%も同じ。8Fで終わると行動なしに戻り、球は保持のまま。後硬直・releaseなし【初期案】。相手から本投げと区別できる表示を出さない。
- 解除：開始より後の時刻の新しい行動入力（primary・secondary・step・feint・summon）、または押しているキーの意図（keys）の変化。行動が不成立でもフリは解除する。視点変更に伴う `move`・`yaw` では解除しない。
- フリ中に本投げを押すと、その時刻から投げ始め8Fを最初から実行する（R06）。
- 危険時計はフリの開始・解除・完了で変わらない。
- 同時刻の優先：ステップ ＞ キャッチ ＞ 跳ね返し・投擲 ＞ フリ ＞ 球召喚（M1細則）。

フェイントが成り立つ目安（標準18.2m、0006）：相手の空振りを見てから投げ直すまで仮に8F＋投げ始め8F＋直球の飛翔約29F＝約45F＜キャッチ空振り54F。余裕は約9F。命中を保証するものではない。

## 練習相手（ボット）

投げる球種を ストレート → 左 → 右 → 上 の順に巡回させ、各方向の跳ね返しを練習できるようにする。4回に1回はフリを入れてから投げる。防御はしない。

## 受け入れ条件

| ID | 期待する振る舞い |
|---|---|
| S5-1 | 2度未満／ちょうど／超過、左右・手前・奥・往復相殺・同値を規定どおりに分類する |
| S5-2 | p−80ms、p+50ms、接触時刻ちょうどのサンプルを含み、それぞれ1単位外を除く |
| S5-3 | 接触前・締切前なら方向を変えられ、接触後・締切後の入力は結果を変えない |
| S5-4 | 進行中の跳ね返しを途中保存して再実行しても同じ結果 |
| S5-5 | 両陣・yaw・斜めの直球・上カーブ・追尾解除後の球で、実際の入射方向が必要な方向になる |
| S5-6 | 入射10度の境界、正面80度の境界。方向が合っても正面範囲外なら失敗 |
| S5-7 | 跳ね返しの方向不一致は被弾・報酬なし・空振り硬直。キャッチは方向に依存せず、受付と評価は従来どおり |
| S5-8 | 防御の成立時に `defense-start` を出す（endsAt＝受付終了）。不成立の押下では出さない |
| S5-9 | フリは開始時だけコスト1（0.25）を消費。不足・非保持・行動中では開始しない。解除・完了で返還しない |
| S5-10 | フリ8F中は球を保持し歩行30%。完了で行動なし・保持のまま、releaseなし |
| S5-11 | 開始時刻と同時の入力・同じ値のkeys・yaw・moveでは解除せず、後の新しい行動入力・keysの変化で解除する |
| S5-12 | フリ開始後どの時点で本投げを押しても、releaseはその押下の8F後だけ |
| S5-13 | フリ中も危険時計は進み、期限が来れば爆発する |
| S5-14 | ボット：球種を巡回し、4回に1回フリを入れる。simのコマンドだけを使う |
