# 0005 追尾球の軌道・接触判定・ステップ解除

- 日付：2026-10-07
- 状態：採用。至近距離の球速下限と球種別の最低飛翔時間はユーザーが確定（企画変更）
- 出典：GPT-6 Astraへの設計相談（読み取りのみ）を親が整理

## 判定形状

| 対象 | 形状（初期案） |
|---|---|
| 試合球 | 半径0.25mの球（rules.md M1細則で直径0.5m） |
| 受け手 | 半径0.30mの縦カプセル。軸は足元から高さ0.30〜1.50m |
| 防御点・発射位置 | 高さ1.20m。カメラ位置・アニメーションで動かさない |

## 軌道

- 誘導点 `G = 受け手の防御点 + 曲がりオフセット O(s)` へ一定速度で向かう。`s` は発射後の移動距離、`L` は発射時の防御点までの距離。
- `u = clamp(s / 0.65L, 0, 1)`、`f(u) = 1 − 3u² + 2u³`。
  - ストレート：O = 0
  - 左カーブ：O = −0.60·L·f(u)·（投げ手の陣の右方向）
  - 右カーブ：O = +0.60·L·f(u)·（同）
  - 上カーブ：O = +0.90·L·f(u)·（上方向）
- `s ≥ 0.65L` 以降はオフセット0の純粋な追尾で、曲がりを再開しない。
- 誘導方向の更新は、球が0.05m進むごと（tick内の事象）。その間は等速直線。誘導点まで0.05m以下になったら以後は純粋な追尾。
- 誘導点は、キャラが動ける範囲に合わせて球の中心で x∈[−10.175, 10.175]、z∈[−17.675, 17.675]（金網の内側。0006で拡大）へ射影する。止まる・落ちる球の範囲は白線の内側（x∈[−6.175, 6.175]、z∈[−15.275, 15.275]）で、別の値として持つ（rules.md M1細則「球の範囲」）。誘導点まで白線の内側に限ると、白線の外にいる相手へ届かずR03が崩れるため。壁際では外向きの曲がりが小さくなるのを許容する。
- 中央のプラズマフェンスは球と衝突しない（feel.md「生体を阻み、コアを通す」）。

参考（静止した相手、中央配置）：最大の横変位は6mで約0.9m、20mで約2.0m。上カーブの最大上昇は6mで約1.25m、20mで約4.1m。

## 歩行で避けられないこと（R03）

純粋な追尾に入った後は、球速 v が最大歩行速度5.75m/s（敏捷10）より速ければ、更新ごとに距離が縮む。球速の下限を6.5m/sにすると、歩行だけでは最終段階でカプセルへの接触を避け続けられない。無効方向のステップ中（約14m/s）は距離が一時的に開きうる（0006で整理）。保証するのは「歩行だけでは追尾が切れない」ことで、「8秒以内に必ず当たる」ことではない（先に防御や爆発が起きればそれで解決する）。

## 球速の決定（企画変更を含む）

```
v_raw = min(基本値 × 攻撃倍率 × 危険倍率 × (1 + ラリー加算), 1.6 × 基本値)
v     = max(6.5, min(v_raw, S_hit / T_min(球種)))
```

- `S_hit`：発射時点で相手が静止していると仮定し、同じ誘導規則で最初に接触するまでの球中心の軌道長。
- `T_min`：**球種別の最低飛翔時間** ストレート240ms／左右カーブ270ms／上カーブ320ms（ユーザー確定）。同じ補正値どうしで「ストレートが最速、上カーブが最遅」を近距離でも保つ。
- **球速の下限6.5m/s**（ユーザー確定）：至近距離ではこの下限が優先し、最低飛翔時間より早く届くことを許す。R03を優先するため。

参考（静止した相手、ストレート／左右／上）：6m 240／270／354ms、14m 480／605／871ms、20m 695／864／1,259ms（基本速度）。

## 接触判定

- 球と受け手の速度が一定の区間ごとに、相対運動の点と「半径0.55mに膨らませたカプセル」の最初の交差時刻を二次方程式で求める（側面の円柱、上下端の球）。初期の重なりは区間の開始時刻。
- 区間は入力、ステップの開始・終了、壁への到達、誘導の更新で区切る。tick末の位置だけで判定しない。
- 接触位置は、カプセル軸上の最近点から球の中心へ向かう方向で、球の表面上の点とする。

時刻の扱い：Astraは「幾何事象は小数時刻のまま」を推奨したが、本作は0004どおり1/60,000秒単位の整数へ切り上げて一度だけ丸める。誤差は約0.017msで判定上は無視でき、同時刻の判定を浮動小数点の等号に頼らずに済むため。

## ステップによる追尾解除

- 球の発射後に、有効な方向のステップが成立した時刻で解除する。その直前の速度で等速直線飛行を続け、重力は加えない。
- 無敵はない。戻った進路で接触すれば被弾する。
- 床・外周への最初の接触で攻撃判定とラリー加算を失い、回収できる球になる。中央フェンスでは失わない。
- 無効な方向のステップは移動だけで、追尾は続く。一時的に距離が開くことはあるが、追尾は解除されない（「無効方向なら必ず当たる」ことは保証しない）。
- ステップ中に新しく投げられた球は、そのステップでは解除されない。
